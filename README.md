A 30-second vertical TikTok video about the same tiny agent-built game — Ghost Runner — on the day it was made and after a week of daily updates. The video cuts between identical moments in the game a week apart (same map, same start, camera still): day 1 is the plain first build, day 7 is visibly busier with flying bats, gems, coin arcs, star and magnet power-ups, combo scoring, particles and parallax scenery. It closes on the day-7 build being played, invites viewers to start their own game at make.fun, and ends with make.fun's referral end card carrying the entrant's referral code.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
